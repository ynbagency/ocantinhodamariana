# Contributing

Use short-lived branches from `main`. Keep commits focused. Never commit `.env`, credentials,
database dumps, private keys or Meta/screen tokens.

Before a pull request:
1. Run PHP syntax checks.
2. Run Raspberry player tests.
3. Run shell syntax checks.
4. If Laravel dependencies are installed, run the Laravel test suite.
5. Explain migrations, security/business-rule changes and manual validation.

Public brand, loyalty economics, privacy rules and external-account permissions require owner approval.
