# Gate 7 — Website, PWA and loyalty foundation

## Delivered
- Public responsive website shell and navigation.
- Today, Menu, O Cantinho, Takeaway, Contacts and Loyalty routes/pages.
- Public pages consume only published menu snapshots.
- Editorial stories/media reused on the public site.
- Installable PWA shell with service worker cache and mobile bottom navigation.
- Customer, loyalty account, immutable transaction ledger, reward and redemption schema.
- Operator customer creation and visit-award workflow.
- Reward definition is configurable and not invented.
- Redemption service uses a DB lock and random one-time secret stored only as SHA-256.

## Deliberately not activated
- Customer self-registration/login.
- Exact reward threshold/economics.
- Public QR self-awarding.
- Real telephone/address/opening hours not yet supplied.
- Online ordering/payment.
These remain gated by business facts or operational approval.
