# Launch runbook

## T-3 days
Freeze structural code except defects. Restore-test backup. Run `cantinho:readiness`.
Commission Pi/TV, perform power/network failure tests and start 72-hour soak.

## T-1
Proofread dishes, prices, phone, address, hours and legal/privacy copy.
Verify Meta only if credentials/permissions are approved. Train operator on the eight daily actions.

## Launch
Publish today's menu, verify public site, local TV version and heartbeat.
Check queue, scheduler, disk and backup status. Technical support keeps incident channel open.

## T+1 / T+7
Review incidents, stale content, operator friction and signage timing. Do not change loyalty economics
from analytics without restaurant approval.
